# 研究：前后端初始化脚手架

## 决策

- 后端源码直接放在仓库根目录，可导入包使用 `app/`。
- 后端使用独立 `pyproject.toml` 和 `uv.lock`，Python 范围固定为 `>=3.11,<3.12`。
- 前端使用 React 19、TypeScript、Vite 和 npm lockfile。
- 只提供一个健康接口；数据库、缓存、模型、SSE、MCP 和业务模块留到后续特性。
- 前端使用 Fetch + AbortController 完成连接检查，不引入额外请求状态库。

## 理由

该方案满足用户指定目录，依赖少、启动快，适合先验证项目边界和开发命令。
后续功能可以在同一目录内按 Speckit 特性逐步增加，不需要为脚手架提前引入生产基础设施。
