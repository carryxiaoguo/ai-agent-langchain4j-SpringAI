# 数据模型：前后端初始化脚手架

本特性不创建数据库表或业务实体。

## 健康响应

| 字段 | 类型 | 规则 |
|---|---|---|
| `status` | 字符串 | 固定为 `ok` |
| `service` | 字符串 | 固定服务名 `ai-agent-api` |
| `request_id` | 字符串 | 与响应头 `X-Request-ID` 一致 |

## 前端连接状态

| 状态 | 含义 |
|---|---|
| `checking` | 正在请求健康接口 |
| `connected` | 后端返回 HTTP 200 |
| `disconnected` | 请求失败、超时或后端返回错误 |
