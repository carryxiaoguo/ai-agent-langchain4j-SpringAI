# 特性规格：前后端初始化脚手架

**特性分支**：`001-project-initialization`

**创建日期**：2026-08-26

**状态**：草稿

**输入**：用户描述：“开始初始化项目，后端放在仓库根目录，前端放到 `ai-agent-frontend`。”

## 用户场景与测试 *(必填)*

### 用户故事 1 - 启动后端（优先级：P1）

作为开发人员，我可以在仓库根目录安装依赖并启动 FastAPI 服务，通过健康接口确认服务已运行。

**独立测试**：执行后端启动和测试命令，访问 `/api/v1/health`，返回 HTTP 200 且响应包含服务名和状态。

**验收场景**：

1. **假设** 已安装 Python 3.11，**当** 执行后端启动命令，**那么** 服务在约定端口监听。
2. **假设** 服务已经启动，**当** 请求健康接口，**那么** 返回稳定 JSON 和 `X-Request-ID`。

---

### 用户故事 2 - 启动前端（优先级：P1）

作为开发人员，我可以在 `ai-agent-frontend/` 目录启动 React 19 页面，看到项目名称、后端地址和连接状态。

**独立测试**：执行前端开发和构建命令，页面能够加载，连接检查在后端可用和不可用时都能显示明确状态。

**验收场景**：

1. **假设** 后端未启动，**当** 打开前端页面，**那么** 页面仍可加载并显示“服务未连接”。
2. **假设** 后端已启动，**当** 点击重新检查，**那么** 页面显示“服务已连接”。

---

### 用户故事 3 - 复现开发命令（优先级：P2）

作为项目维护人员，我可以从根目录文档了解目录职责、安装、启动、测试和构建命令。

**独立测试**：在干净终端按文档执行前后端命令，安装、检查、测试和构建均可复现。

**验收场景**：

1. **假设** 新开发人员只有 Python 3.11 和 Node.js，**当** 按文档操作，**那么** 能分别启动两个项目。
2. **假设** 没有真实密钥，**当** 复制示例环境文件，**那么** 项目仍可完成脚手架构建。

### 边界场景

- 后端未启动时，前端不能显示未定义的“已连接”。
- 健康接口失败时，前端必须给出重试入口，而不是白屏。
- 配置文件只提供示例值，不得包含真实密钥。
- 端口被占用时，启动命令必须返回清晰错误。

## 需求 *(必填)*

### 功能需求

- **FR-001**：仓库根目录必须包含后端源码和 `ai-agent-frontend/` 前端目录。
- **FR-002**：后端必须使用 Python 3.11、FastAPI，并提供明确的开发启动入口。
- **FR-003**：后端必须提供 `GET /api/v1/health`，返回 `status`、`service` 和 `request_id`。
- **FR-004**：前端必须使用 React 19、TypeScript 和 Vite，并提供开发与生产构建命令。
- **FR-005**：前端必须从环境变量读取后端地址，并提供连接检查和重新检查操作。
- **FR-006**：两个项目都必须提供示例环境配置、依赖锁定和最小自动化测试。
- **FR-007**：根目录必须提供中文开发文档，说明目录、安装、启动、测试和构建。
- **FR-008**：本特性不得实现聊天、RAG、智能体、工具、MCP、数据库或正式身份体系。

### API 与流式需求 *(对外能力必填)*

- **API-001**：健康接口必须具有稳定路径、状态码和 JSON 字段。
- **API-002**：服务端必须接受合法的 `X-Request-ID`，未提供时自动生成，并在响应头返回。
- **API-003**：本特性不实现 SSE；后续流式能力必须另建特性和契约。

### 安全与隐私需求 *(必填)*

- **SEC-001**：环境示例、日志和前端构建产物不得包含有效密钥。
- **SEC-002**：前端不得把后端地址和配置写死在业务组件中。

### 可靠性与可观测性需求 *(必填)*

- **REL-001**：前端连接检查必须设置超时，并允许用户手动重试。
- **OBS-001**：健康接口响应中的 `request_id` 必须与 `X-Request-ID` 一致。

### AI 行为与评测

本特性不引入模型、Prompt、Embedding、RAG 或工具调用，因此不创建 AI 评测集。

## 成功标准 *(必填)*

### 可量化结果

- **SC-001**：开发人员在 10 分钟内可以完成两个项目的依赖安装和本地启动。
- **SC-002**：后端健康接口在本地正常启动时返回 HTTP 200，响应时间 P95 小于 1 秒。
- **SC-003**：后端测试、静态检查和前端测试、类型检查、生产构建全部通过。
- **SC-004**：前端在 390 像素和 1440 像素视口下无横向溢出或控件重叠。
- **SC-005**：扫描仓库和前端构建产物时，有效密钥检出数量为 0。

## 假设

- 开发环境使用 Python 3.11、Node.js 20 以上和 npm。
- 仓库根目录就是后端项目目录；Python 可导入包使用合法名称 `app`。
- 本项目不提供本地部署方案；本地仅保留前后端开发启动命令。
- 后续业务特性必须继续通过 Speckit 独立规划和实现。
