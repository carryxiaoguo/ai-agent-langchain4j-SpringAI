### 组件边界说明

| 区域 | 主要职责 | 关键实现 |
| --- | --- | --- |
| 前端 | 页面路由、聊天窗口、SSE 增量渲染 | `yu-ai-agent-frontend/src/views`、`src/api/index.js` |
| HTTP 接入 | 将同步/流式请求转发给应用服务 | `AiController`，应用上下文为 `/api` |
| 恋爱大师 | 多轮对话、结构化报告、RAG、工具/MCP 调用能力 | `LoveApp` |
| 超级智能体 | 面向复杂任务的自主规划和多步执行 | `YuManus`、`ReActAgent`、`ToolCallAgent` |
| 工具层 | 文件、搜索、网页、下载、终端、PDF、终止工具 | `ToolRegistration` + `ToolCallback[]` |
| RAG 层 | 文档加载、Embedding、向量检索、查询重写 | `src/main/java/.../rag` |
| MCP 层 | 将外部 MCP Server 暴露为 Spring AI 工具 | `mcp-servers.json`、MCP Client |

## 3. AI 恋爱大师请求链路

```mermaid
sequenceDiagram
    participant U as 用户浏览器
    participant F as LoveMaster.vue
    participant C as AiController
    participant L as LoveApp
    participant M as ChatMemory
    participant R as RAG Advisor
    participant V as SimpleVectorStore
    participant Q as DashScope ChatModel

    U->>F: 输入问题与 chatId
    F->>C: GET /api/ai/love_app/chat/sse
    C->>L: doChatByStream(message, chatId)
    L->>M: 读取/写入会话窗口（最多 20 条消息）
    L->>Q: 组合系统提示词、历史与用户问题
    opt 调用 doChatWithRag 时
        L->>R: 查询重写并执行 RAG Advisor
        R->>V: 相似度检索恋爱知识文档
        V-->>R: 返回相关文档上下文
        R->>Q: 将检索上下文加入模型请求
    end
    Q-->>L: Flux<String> 增量内容
    L-->>C: 响应式流
    C-->>F: text/event-stream
    F-->>U: 逐段更新 AI 消息，收到 [DONE] 后关闭连接
```

## 4. YuManus 超级智能体执行链路

```mermaid
flowchart TD
    request["GET /api/ai/manus/chat?message=..."]
    controller["AiController<br/>创建 YuManus"]
    run["BaseAgent.runStream<br/>CompletableFuture + SseEmitter"]
    state["状态机<br/>IDLE -> RUNNING -> FINISHED / ERROR"]
    loop{"currentStep < maxSteps?<br/>YuManus maxSteps=20"}
    think["ToolCallAgent.think<br/>拼接 Prompt + 调用 ChatModel"]
    decide{"模型是否返回工具调用?"}
    answer["记录 AssistantMessage<br/>当前步骤结束"]
    act["ToolCallAgent.act<br/>ToolCallingManager 执行工具"]
    result["写回工具响应与会话历史"]
    terminate{"调用 doTerminate?"}
    done["SSE 推送步骤结果<br/>complete emitter"]
    error["标记 ERROR<br/>推送错误并清理"]

    request --> controller --> run --> state --> loop
    loop -- 否 --> done
    loop -- 是 --> think --> decide
    decide -- 否 --> answer --> loop
    decide -- 是 --> act --> result --> terminate
    terminate -- 是 --> done
    terminate -- 否 --> loop
    think -.异常.-> error
    act -.异常.-> error
```

超级智能体可调用的本地工具如下：

| 工具 | 外部副作用/数据源 |
| --- | --- |
| `FileOperationTool` | `tmp/file` 下读写文本 |
| `WebSearchTool` | SearchAPI 的百度搜索接口，取前 5 条结果 |
| `WebScrapingTool` | Jsoup 抓取网页 HTML |
| `ResourceDownloadTool` | 下载 URL 资源到 `tmp/download` |
| `TerminalOperationTool` | 通过 `cmd.exe /c` 执行命令 |
| `PDFGenerationTool` | iText 生成 PDF 到 `tmp/pdf` |
| `TerminateTool` | 返回“任务结束”，让 Agent 进入 `FINISHED` |

## 5. MCP 集成架构

```mermaid
flowchart LR
    app["Spring Boot 主应用"]
    provider["Spring AI MCP Client<br/>ToolCallbackProvider"]
    config["mcp-servers.json"]
    amap["amap-maps<br/>npx @amap/amap-maps-mcp-server<br/>stdio"]
    image["yu-image-search-mcp-server<br/>Spring Boot MCP Server"]
    pexels["Pexels REST API"]
    sse["HTTP SSE :8127<br/>可选传输方式"]

    app --> provider
    config --> provider
    provider -->|stdio 子进程| amap
    provider -->|stdio Java -jar| image
    provider -.SSE 连接.-> sse
    image --> pexels
```

`yu-image-search-mcp-server` 通过 `MethodToolCallbackProvider` 注册 `ImageSearchTool.searchImage`，调用 Pexels `/v1/search` 并返回中等尺寸图片 URL。主应用的 MCP 配置目前被注释，启用前需要：

1. 填入高德、Pexels、DashScope 等 API Key。
2. 构建图片 MCP 子模块，生成 `yu-image-search-mcp-server/target/*.jar`。
3. 在 `application.yml` 启用 stdio 配置，或启动 MCP Server 的 SSE 模式（默认端口 `8127`）并配置连接地址。

### 关键运行配置

| 配置项 | 默认值/位置 | 影响 |
| --- | --- | --- |
| 后端端口 | `8123` | Spring Boot HTTP 服务 |
| 应用上下文 | `/api` | 所有后端 API 的前缀 |
| DashScope 模型 | `qwen-plus` | ChatModel 与 EmbeddingModel 来源 |
| Ollama | `http://localhost:11434`、`gemma3:1b` | 本地模型示例，当前业务链路未默认使用 |
| 恋爱知识文档 | `src/main/resources/document/*.md` | 启动时加载到内存向量库 |
| MCP 图片服务 | `8127`（SSE）或 stdio | 外部图片搜索工具 |
| 前端开发 API | `http://localhost:8123/api` | `yu-ai-agent-frontend/src/api/index.js` |
