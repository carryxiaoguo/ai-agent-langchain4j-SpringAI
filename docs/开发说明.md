# 开发说明

## 环境

- Python 3.11
- uv
- Node.js 20 以上
- npm

## 目录

- `app/`：根目录下的 FastAPI 后端源码。
- `tests/`：后端自动化测试。
- `ai-agent-frontend/`：React 19 + TypeScript 前端。
- `specs/`：按 Speckit 管理的规格、计划、契约和任务。

## 后端

```powershell
uv sync
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

健康接口：`http://127.0.0.1:8000/api/v1/health`

```powershell
uv run ruff check .
uv run python -m pytest
```

## 前端

```powershell
Set-Location ai-agent-frontend
npm.cmd install
npm.cmd run dev -- --host 127.0.0.1 --port 3000
```

打开 `http://127.0.0.1:3000`。

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run test -- --run
npm.cmd run build
```

## 边界

本文只说明本地开发启动，不提供本地部署方案。初始化阶段不连接数据库、缓存、
对象存储或模型服务。
后续能力必须新增 Speckit 特性，并同步更新规格、计划和任务。
